# Complexity Analysis Results

This document presents comprehensive complexity analysis results comparing text complexity metrics across different datasets. Each metric is analyzed using multiple visualization types to provide a complete understanding of the complexity patterns.

## Plot Types

For each complexity metric, four different plot types are provided:

1. **Grouped Plots**: Show the distribution of complexity values across different text categories or levels
2. **Boxplots**: Display the statistical distribution (median, quartiles, outliers) of complexity values
3. **Trimmed Plots**: Show distributions with extreme outliers removed for clearer visualization
4. **Boxplots Trimmed**: Statistical distributions with outliers removed

## Datasets

- **ASSET DATASET**: Academic text complexity analysis using the ASSET dataset
- **WIRED DATASET**: Popular science text complexity analysis using the WIRED dataset

## Metrics Included

The analysis covers various linguistic and cognitive complexity dimensions including:
- **Lexical Complexity**: Word frequency, age of acquisition, concreteness, familiarity
- **Syntactic Complexity**: Sentence length, clause structure, dependency parsing
- **Semantic Complexity**: Concept density, knowledge graph metrics, WordNet relationships
- **Readability Metrics**: Various readability indices and academic level assessments
- **Cohesion Metrics**: Referential cohesion, narrative structure, connective usage

## Section Structure

Each metric section follows this consistent structure with 4 images per row:

```
## [METRIC_NAME]

### ASSET DATASET
[Grouped Plot] [Boxplots] [Trimmed Plot] [Boxplots Trimmed]

### WIRED DATASET
[Individual Plot] [Individual Boxplots] [Dialog Plot] [Dialog Boxplots]
```

The plots are arranged horizontally for easy comparison across visualization types and datasets.
