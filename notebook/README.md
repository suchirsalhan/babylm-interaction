- `age_system_prompts.txt`: 6 prompts, designed to target the expected knowledge a child should have at that age. The prompts were designed based on the curriculum shared [here](https://www.notion.so/Interaction-prompts-1ce59d5b126e80fb927bf14cc6e1aefb)
- `age_user_prompt.txt`: The text used for the "user" role when building the Llama chat template. The final Llama prompt looked something like this:
  ```code
  system
  
  Cutting Knowledge Date: December 2023
  Today Date: 08 Aug 2025
  
  You are an expert dialogue assistant.
  
  Your task is to start a dialogue between you and a child model with the linguistic abilities of a child who is 6-11 months old.
  You MUST be concise. Generate a conversation starter that consists of 1 to 2 sentences and is no more than 30 words total.
  The conversation starter MUST draw upon the provided "Expected Knowledge" given below.
  Output the conversation starter only. DO NOT include in the output anything else and stick to the "Generation Criteria" below.
  You MUST format your answer as a text within double quoutes.
  
  ## Expected knowledge
  - Objects
  
  ## Generation criteria
  # Tone
  - Ensure the tone is friendly and conversational.
  - The tone MUST be positive and sensible to the child model's age.
  
  # Content
  - The text MUST focus on recognising names of a few objects.
  - The text MUST avoid questions that can be answered with a single word (e.g., 'yes', 'no', 'good', 'bad').user
  
  Generate a conversation starter to engage a child model in a dialogue.assistant
  ```
- `babyLM_Llama-3.2-3B_dialogue_starters_2025-08-08.xlsx`: An excel file with dialogue (conversation) starters generated by the indicated Llama model. Each prompt in `age_system_prompts.txt` was used to generate 100 starters. So, the file has 600 starters total. The file has one sheet per prompt used. The code used to generate the conversation starters is in our shared Google Drive [here](https://colab.research.google.com/drive/1Qv8HAlkfCwyEXSDGiZtS_88u0d1ijl0d?usp=drive_link)
